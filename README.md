# SIGHT

Public classify page for a Solana signature.

Live on the 35 domain: https://35.elghaly.dev/sight/

Source repo: https://github.com/Alarm2024/35-sight

Closed desk (other project): https://35.elghaly.dev

## Product

- Input: public transaction signature only
- Output: Class A / B / C
- No wallet connect, no seed, no 2FA, no remote control
- Languages on page: EN / RU / 中文 / DE / ES
- Arabic stays off this repo

## Lanes

- One signature class: free
- Address-wide scan: paid quote by mail (`SIGHT PAY`)
- Cannot pay: mail `support@elghaly.dev` subject `HUMAN`
- Payment is USDC by invoice. Never to the 35 credit / Squads vault

## Deploy

GitHub Pages from `main`. The custom host `35.elghaly.dev/sight/` is published from `Alarm2024/35` (`sight/index.html`) so the closed-desk CNAME is not touched.
