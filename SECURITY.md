# Security

SIGHT reads public Solana signatures only.

Never accept, store, or log seed phrases, private keys, 2FA codes, or passwords.

Reject pastes that look like 12–24 word phrases, 64-byte JSON secret arrays, or 87–88 character secret key material.

No wallet adapter. No signTransaction. No sendTransaction.

Do not route paid USDC to the 35 credit Squads vault.
